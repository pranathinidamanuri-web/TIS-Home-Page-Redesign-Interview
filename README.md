# Tulas International School (TIS) - Homepage Redesign

A modern, animated, and responsive redesign of the Tulas International School homepage. This project focuses on improving user experience, visual hierarchy, and engagement using smooth animations and a clean UI.

---

## 🚀 Live Demo

* **Live URL:** [Add Vercel Link After Deployment]
* **Repository:** https://github.com/pranathinidamanuri-web/TIS-Home-Page-Redesign-Interview

---

## 🛠️ Tech Stack

* **Framework:** React.js (Vite)
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Deployment:** Vercel

---

## ✨ Standout Features Implemented

1. **Custom Cursor**

   * Interactive cursor that follows mouse movement.
   * Expands when hovering over buttons and interactive elements.
   * Disabled on mobile devices for better performance.

2. **Scroll-Based Animations**

   * Sections animate smoothly on scroll using Framer Motion.
   * Improves user engagement and modern UI feel.

3. **Scroll Progress Bar**

   * Displays how much of the page the user has scrolled.
   * Enhances navigation awareness.

## 📦 Getting Started Locally

### 1. Clone the repository

```bash
git clone https://github.com/pranathinidamanuri-web/TIS-Home-Page-Redesign-Interview.git
cd TIS-Home-Page-Redesign
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```

### 4. Open in browser

```
http://localhost:5173
```
